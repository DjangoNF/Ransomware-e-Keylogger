Projeto Educacional: Ransomware e Keylogger em Python
📌 Sobre o Projeto
Este projeto foi desenvolvido com fins educacionais para demonstrar o funcionamento de algumas técnicas utilizadas em ataques cibernéticos, permitindo o estudo de conceitos relacionados à segurança da informação, análise de ameaças e mecanismos de defesa.

O objetivo principal é compreender como essas ameaças operam para que profissionais e estudantes de cibersegurança possam desenvolver melhores estratégias de prevenção, detecção e mitigação.

📂 Estrutura do Projeto
O repositório contém os seguintes arquivos:

🔐 ransomware.py
Script desenvolvido para demonstrar, em ambiente controlado, o processo de criptografia de arquivos utilizando a biblioteca Fernet, disponível no pacote cryptography.

Principais conceitos abordados:

Criptografia simétrica;
Geração e utilização de chaves criptográficas;
Proteção de dados;
Funcionamento básico de um ransomware.
⌨️ keylogger.py
Script demonstrativo que utiliza a biblioteca pynput para registrar eventos do teclado.

Principais conceitos abordados:

Captura de eventos de entrada;
Monitoramento de teclado;
Riscos associados à coleta indevida de informações;
Técnicas de detecção e prevenção contra keyloggers.
📄 resumo.txt
Arquivo contendo um pequeno relatório sobre a importância do profissional de cibersegurança na prevenção e combate a ameaças digitais como ransomware e keyloggers.

🛠️ Tecnologias e Bibliotecas Utilizadas
Python 3
Fernet (cryptography)
pynput
Instalação das dependências:

pip install cryptography pynput
🎯 Objetivos de Aprendizagem
Este projeto busca proporcionar conhecimento sobre:

Criptografia aplicada à segurança da informação;
Técnicas utilizadas por malware;
Análise de ameaças cibernéticas;
Boas práticas de segurança digital;
Desenvolvimento de uma mentalidade defensiva na área de cibersegurança.
⚠️ Aviso Importante
Este projeto foi desenvolvido exclusivamente para fins educacionais, acadêmicos e de pesquisa. Seu objetivo é auxiliar no aprendizado sobre ameaças cibernéticas e preparar futuros profissionais de cibersegurança para identificar, analisar e se proteger contra esse tipo de ataque.

O uso deste conhecimento para atividades ilegais, invasões, coleta não autorizada de informações ou qualquer ação que viole leis e normas de segurança é totalmente desencorajado. Os autores não se responsabilizam por qualquer utilização indevida do conteúdo apresentado.

Conhecer como um ataque funciona é uma das melhores formas de aprender a se defender dele e contribuir para a formação de profissionais mais qualificados na área de cibersegurança.
